# 物业全能管家智能体系统 - 设计文档

## 一、系统概述

本系统是一个基于AI的物业服务管理平台，旨在帮助物业公司从"被动收物业费"转型为"社区生活运营商"。

## 二、核心功能模块

### 1. 移动端（业主端）

#### 1.1 首页
- **通知栏**：显示重要通知和公告
- **轮播图**：4张可配置的轮播图，支持链接跳转
- **快捷入口**：
  - 智能便民（飞书表单查询）
  - 服务大家（飞书表单录入）
  - 投诉建议（飞书表单录入）
  - 小区活动（H5落地页）
- **智能搜索框**：
  - 支持模糊查询
  - 意图识别（如"1栋1单元302空调坏了"识别出"空调"）
  - 自动筛选维修记录
  - 多条记录按评分降序显示
  - 电话一键拨号
  - 无记录时查询10km内评分4.0以上的商家
- **底部导航**：首页、分类、订单、我的

#### 1.2 服务分类
- 维修服务（水电、家电、门窗、管道）
- 生活服务（家政、搬家、快递、绿植）
- 社区服务（停车、门禁、访客、快递柜）

#### 1.3 订单管理
- 订单列表
- 订单状态（待接单、进行中、已完成）
- 服务人员信息
- 订单详情

#### 1.4 个人中心
- 用户信息
- 我的账单
- 我的收藏
- 我的家人
- 设置

### 2. PC管理端

#### 2.1 控制台
- 数据概览（用户数、订单数、收入、增长率）
- 快捷操作入口

#### 2.2 内容管理
- **轮播图管理**：增删改查轮播图
- **通知管理**：发布和管理通知公告

#### 2.3 人员管理
- **维修人才库**：
  - 自有员工管理
  - 技能标签（水电、木工、智能锁等）
  - 持证情况
  - 服务评分
  - 社区合伙人管理

#### 2.4 服务商管理
- 外部服务商信息
- 评分和距离
- 推荐规则配置

#### 2.5 订单管理
- 订单列表
- 订单详情
- 派单管理
- 订单统计

#### 2.6 数据统计
- 订单统计
- 收入统计
- 用户统计
- 服务商统计

### 3. 后端服务

#### 3.1 核心API
- 用户认证与授权
- 轮播图接口
- 通知接口
- 智能搜索接口
- 维修人才库接口
- 订单管理接口

#### 3.2 智能派单系统
- **就近派单**：基于LBS定位
- **技能匹配**：根据故障类型匹配技师
- **负荷均衡**：避免单个师傅订单堆积

#### 3.3 外部服务商推荐引擎
- 自动抓取大众点评、美团等平台数据
- 筛选标准：
  - 距离 < 10km
  - 评分 > 4.0
  - 营业中
  - 无重大投诉记录
- 推荐Top 5优质商家

## 三、技术架构

### 3.1 前端技术栈
- **移动端**：React + Vite + Ant Design Mobile
- **PC管理端**：React + Vite + Ant Design
- **路由**：React Router
- **HTTP客户端**：Axios

### 3.2 后端技术栈
- **运行环境**：Node.js
- **Web框架**：Express
- **数据库**：MongoDB
- **API风格**：RESTful

### 3.3 部署架构
- 前端：静态资源部署（Nginx/CDN）
- 后端：Node.js服务器
- 数据库：MongoDB集群

## 四、业务流程

### 4.1 维修服务流程
1. 业主提交维修需求（如"空调不制冷"）
2. 系统进行意图识别
3. 查询物业人才库
4. 智能派单给合适的技师
5. 技师接单并上门服务
6. 服务完成后业主评价
7. 如无合适技师，推荐外部服务商

### 4.2 外部服务商推荐流程
1. 系统检测到内部人才库无法覆盖
2. 自动抓取周边服务商信息
3. 按距离、评分、营业状态筛选
4. 推荐Top 5商家
5. 业主选择并联系
6. 系统记录服务结果

## 五、盈利模式

### 5.1 内部降本增效
- 减少外包依赖
- 预测性维护

### 5.2 流量分发与佣金
- 生活服务导流（10%-15%佣金）
- 本地生活O2O

### 5.3 社区团购与电商
- 基于信任的零售
- 源头直采

### 5.4 数据增值服务
- 供应链优化
- 保险分润

### 5.5 SaaS化输出
- 系统打包销售给其他物业公司
- 年费模式
